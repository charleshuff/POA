* Prompt: Build "Equipment Replacement Info" Single-File HTML Webpage

** Overview

Create a single-file HTML webpage called "Equipment Replacement Info" with all CSS in a =<style>= tag and all JavaScript in a =<script>= tag. The page must be fully functional, mobile-responsive, and use a light/clean theme. Use no external dependencies except =pdf-lib= loaded via CDN:

#+begin_example
https://unpkg.com/pdf-lib@1.17.1/dist/pdf-lib.min.js
#+end_example

** Overall Behavior

- All form fields (text, select, textarea, radio, number) must auto-save to =sessionStorage= on every =input= / =change= event so data survives page refreshes.
- On page load, all fields must be restored from =sessionStorage=, including radio button checked states and select dropdown values.
- Blank fields must be *OMITTED entirely* from the generated summary — no empty lines, no orphaned section headers.
- The page must be fully usable on mobile phones (responsive layout, stacked buttons on small screens, appropriate input types).
