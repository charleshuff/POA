* Call List Parser — Single-File HTML Website Generation Prompt

** Overview

Generate a single, self-contained HTML file (no external dependencies) that serves as
a "Call List Parser" website. The website accepts HTML exported from an ETMS service
management system and parses it into a simplified list of call cards with copy-to-clipboard
functionality.

** Source HTML Structure

The input HTML comes from the ETMS Home Page (hosted at =https://etms.pacificoffice.com/=).
The critical structural details are as follows:

*** Technician (Global — One Per Page)

The technician name is the *logged-in user* and appears ONCE on the entire page inside
a settings panel. It applies to ALL calls on the page. It is located at:

#+begin_src html
<div data-role="panel" id="settingsPanel" data-position="right">
    <p>
        <strong>Charles Huff (20SR20) </strong>
    </p>
</div>
#+end_src

- The format is: =Full Name (TechCode)=
- Extract ONLY the name portion before the parenthesis.
- Example: ="Charles Huff (20SR20)"= → ="Charles Huff"=
- Fallback: if =#settingsPanel= is not found, look for the header link
  =<a href="#settingsPanel">= and use its text content.

*** Call List Items

Each call is an =<li>= element with a =data-call-id= attribute:

#+begin_src html
<li data-call-id="88095">
    <a href="/Home/CallDetails/88095" title="Columbia Hospitality">
        ...call content...
    </a>
</li>
#+end_src

*** Fields to Extract Per Call

**** 1. Title (Customer)
- Location: =<h3>= tag inside the =<li>=
- Example: =<h3>Columbia Hospitality</h3>= → ="Columbia Hospitality"=

**** 2. Contact
- Location: A =<p style="white-space: normal;">= that contains a =<strong>= child,
  where that =<p>= does NOT contain any of these strings:
  - =|= (pipe character — that's the address line)
  - ="Description:"=
  - ="Equipment Note:"=
  - ="Hours:"=
  - ="Item No.(Model):"=
- The contact name (and optionally phone number) is inside the =<strong>= tag.
- Example: =<strong>BRITTANY DOUST 360-742-7117</strong>= → ="BRITTANY DOUST 360-742-7117"=
- Some contacts are placeholder dashes like =<strong> --  -- </strong>=.
  If the text matches only dashes/spaces (regex: =/^[\s\-]+$/=), treat it as ="N/A"=.

**** 3. City
- Location: A =<p>= containing a pipe character =|= but NOT containing ="Call Type"=.
- Format: ="Street Address | City, ST ZIP"=
- Example: ="2200 Alaskan Way #200 | Seattle, WA 98121"= → ="Seattle"=
- Parse: split on =|=, take the second part, then match =/^([A-Za-z\s.'-]+),/= to
  extract the city name before the comma.

**** 4. Item No. (Model)
- Location: A =<p>= containing the text ="Item No.(Model):"=
- Use regex: =/Item No\.\(Model\):\s*(.*?)\s*Serial:\s*(.*?)\s*Equipment:\s*(.*)/=
- Capture group 1 = Item No. (Model)
- Example value: ="CB751I"=

**** 5. Serial Number
- Same =<p>= and regex as Item No. above.
- Capture group 2 = Serial Number
- Example value: ="ADXD011005724"=

**** 6. Equipment ID
- Same =<p>= and regex as Item No. above.
- Capture group 3 = Equipment ID
- Example value: ="8C28041"=

**** 7. Technician
- This is the GLOBAL value extracted from =#settingsPanel= as described above.
- It is the SAME for every call on the page.
- It is NOT the name found in the Description field (that is an installer name, not the technician).

** Website Features

*** Header Section
1. Title: "📋 Call List Parser"
2. Subtitle: "Paste HTML from your clipboard or upload an HTML file to extract call information"
3. Two navigation links displayed as pill-shaped buttons side by side:
   - "📝 Open Call Notes Page" → links to =https://charleshuff.github.io/POA/call_notes.html= (opens in new tab)
   - "🌐 Open ETMS" → links to =https://etms.pacificoffice.com/= (opens in new tab)

*** Control Buttons
Three action buttons centered horizontally:
1. "📋 Paste from Clipboard" — reads HTML from the user's clipboard using =navigator.clipboard.readText()=, parses it, and renders call cards.
2. "📁 Upload HTML File" — opens a hidden file input (=accept=".html,.htm"=), reads the file with =FileReader=, parses it, and renders call cards.
3. "🗑️ Clear All" — clears all parsed data from the page AND from =sessionStorage=.

*** Status Bar
- A centered status message area below the controls.
- Shows success (green), error (red), or info (blue) messages.
- Messages auto-dismiss after 5 seconds.

*** Call Cards
For each parsed call, render a card containing:
1. A header row with:
   - Left: call number badge ("Call #1", "Call #2", etc.)
   - Right: two action buttons side by side:
     a. "📋 Copy to Clipboard" (green) — copies that call's formatted text to clipboard.
        Shows "✅ Copied!" feedback for 2 seconds.
     b. "🔗 Copy & Open Call Notes" (blue) — copies the call's formatted text to clipboard
        AND opens =https://charleshuff.github.io/POA/call_notes.html= in a new tab.
        Shows "✅ Copied! Opening..." feedback for 2 seconds.
2. A grid of fields (2 columns on desktop, 1 column on mobile):
   - Title (Customer) — full width spanning both columns
   - Contact
   - Technician
   - City
   - Item No. (Model)
   - Serial Number
   - Equipment ID
3. Fields with value "N/A" should be displayed in dim italic text.

*** Clipboard Text Format
When copying a call, use this exact format:
#+begin_example
Title (Customer): Columbia Hospitality
Contact: CHAD FARHINGER
Technician: Charles Huff
City: Seattle
Item No. (Model): CB751I
Serial Number: ADXD011005724
Equipment ID: 8C28041
#+end_example

*** Session Persistence
- Use =sessionStorage= (NOT =localStorage=) to persist parsed call data across page refreshes.
- Key: ="callParserData"=
- On page load, check =sessionStorage= for saved data. If found, restore and render the calls
  with a "♻️ Restored from session" badge displayed above the call count.
- Save to =sessionStorage= every time new HTML is parsed (paste or file upload).
- Clear =sessionStorage= when the user clicks "Clear All".

** Technical Requirements

1. Single HTML file — all CSS in a =<style>= tag, all JS in a =<script>= tag.
2. No external libraries, frameworks, or CDN dependencies.
3. Use =DOMParser= to parse the input HTML string.
4. Use =document.createTreeWalker= or =querySelectorAll= for DOM traversal.
5. Use =navigator.clipboard.writeText()= for copying.
6. Use =navigator.clipboard.readText()= for pasting.
7. Use =window.open(url, '_blank', 'noopener,noreferrer')= for opening external links.
8. Escape all user-sourced text before inserting into the DOM to prevent XSS
   (create a temporary =div=, set =textContent=, read =innerHTML=).
9. All =try/catch= around =sessionStorage= and clipboard operations for graceful error handling.
10. The file input should reset its value after each upload so the same file can be re-uploaded.
